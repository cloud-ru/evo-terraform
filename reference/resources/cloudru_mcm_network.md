
# cloudru_mcm_network (Resource)

Частная сеть проекта. Название, описание и признак сети по умолчанию меняются на месте, параметры адресации задаются при создании.

## Example Usage

```terraform
resource "cloudru_mcm_network" "private" {
  # Название (1–255 символов), описание (до 255 символов) и признак сети по умолчанию меняются на месте.
  name        = "net-private-01"
  description = "Сеть приложений"
  is_default  = false

  # Параметры ниже задаются при создании: при изменении сеть будет пересоздана.
  platform_name = "openstack-01"
  subnet_range  = "192.168.10.0/24"
  gateway       = "192.168.10.1"
  dns           = ["8.8.8.8", "1.1.1.1"]
  enable_dhcp   = true
}
```

## Schema

### Required

- `name` (String) Название сети, от 1 до 255 символов.
- `platform_name` (String) Название платформы виртуализации, на которой создаётся сеть. При изменении ресурс будет пересоздан.
- `subnet_range` (String) Диапазон IP-адресов сети в нотации CIDR, например `192.168.10.0/24`. При изменении ресурс будет пересоздан.

### Optional

- `description` (String) Описание сети, до 255 символов.
- `dns` (List of String) Адреса DNS-серверов, которые получит подсеть сети при создании. При изменении ресурс будет пересоздан.
- `enable_dhcp` (Boolean) Признак включённого DHCP в подсети сети при создании. При изменении ресурс будет пересоздан.
- `gateway` (String) Адрес шлюза. При изменении ресурс будет пересоздан.
- `is_default` (Boolean) Признак сети по умолчанию в проекте. Если не задан, остаётся значение платформы.

### Read-Only

- `id` (String) Идентификатор сети.

### Зависимости

#### Platform

``platform_name`` — название платформы виртуализации проекта. Его можно посмотреть в консоли MCM.

### Ограничения

- ``name``, ``description`` и ``is_default`` меняются на месте; ``platform_name``, ``subnet_range``, ``gateway``, ``dns`` и ``enable_dhcp`` задаются при создании, их изменение пересоздаёт сеть.
- DNS и DHCP после создания управляются подсетью — ресурсом ``cloudru_mcm_subnet``.
- Сеть по умолчанию удалить нельзя: сначала снимите признак ``is_default``.
- При импорте параметры, заданные только при создании, не восстанавливаются: если они есть в конфигурации, план предложит пересоздать сеть.
