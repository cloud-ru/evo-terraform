### Зависимости

Перечисленные ниже ресурсы/датасорсы используются для создания/изменения виртуальной машины с помощью Terraform

#### Flavor

Нужное значение для флейвора (``id`` или ``name``) можно получить с помощью датасорса ``cloudru_evolution_compute_flavor_collection``.

#### Zone

Нужное значение для зоны доступности (``id`` или ``name``) можно получить с помощью датасорса ``cloudru_evolution_compute_zone_collection``.

#### Disks

Нужное значение для диска (``id``) можно получить с помощью датасорса ``cloudru_evolution_compute_disk_collection``. Если нужного Вам диска не существует, то его можно создать с помощью ресурса ``cloudru_evolution_compute_disk``.

#### Image metadata

Нужное значение для Image metadata можно получить с помощью датасорса ``cloudru_evolution_compute_image_collection``.

После получения информации об образе необходимо просмотреть поля ``image_metadata`` - обращаем внимание на поле ``mandatory_group``,
например, ``public_key`` и ``linux_password`` относятся к одной ``"mandatory_group"``: ``"authentication"``.
Для создания ВМ с данным образом должна быть передана map `image_metadata` - с полями, которые покрывают каждую mandatory_group.
Например, для примера выше либо ``public_key`` либо ``linux_password`` - так как они относятся к одной группе.

```terraform
image_metadata = {
  public_key = {
    string_value = "demo"
  }
}
```

#### Network interfaces

Нужное значение для сетевого интерфейса (``id``) можно получить с помощью датасорса ``cloudru_evolution_compute_interface_collection``. Если нужного Вам интерфейса не существует, то его можно создать с помощью ресурса ``cloudru_evolution_compute_interface``.

#### Placement group

Нужное значение для группы размещения (``id``) можно получить с помощью датасорса ``cloudru_evolution_compute_placement_group_collection``. Если нужной Вам группы размещения не существует, то ее можно создать с помощью ресурса ``cloudru_evolution_compute_placement_group``.
