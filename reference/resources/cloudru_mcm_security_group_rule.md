
# cloudru_mcm_security_group_rule (Resource)

Отдельное правило группы безопасности. Изменение любого параметра пересоздаёт правило.

## Example Usage

```terraform
resource "cloudru_mcm_security_group_rule" "metrics" {
  # Изменение любого поля пересоздаёт правило.

  # Идентификатор группы безопасности.
  security_group_id = cloudru_mcm_security_group.web.id

  # Направление: ingress — входящий, egress — исходящий.
  direction = "ingress"

  # Протокол: tcp, udp, icmp или any.
  protocol = "tcp"

  # Диапазон портов; для одного порта значения совпадают.
  port_range_min = "9100"
  port_range_max = "9100"

  # Источник трафика: remote_ip_prefix или remote_group_id (не вместе).
  remote_ip_prefix = "10.0.0.0/8"

  # Описание правила (необязательно).
  description = "node exporter"
}
```

## Schema

### Required

- `direction` (String) Направление трафика: `ingress` — входящий, `egress` — исходящий. При изменении ресурс будет пересоздан.
- `protocol` (String) Протокол: `tcp`, `udp`, `icmp` или `any`. При изменении ресурс будет пересоздан.
- `security_group_id` (String) Идентификатор группы безопасности. При изменении ресурс будет пересоздан.

### Optional

- `description` (String) Описание правила. При изменении ресурс будет пересоздан.
- `port_range_max` (String) Конец диапазона портов. Для одного порта совпадает с `port_range_min`. При изменении ресурс будет пересоздан.
- `port_range_min` (String) Начало диапазона портов. Не задаётся, если правило действует на все порты. При изменении ресурс будет пересоздан.
- `remote_group_id` (String) Идентификатор группы безопасности на другой стороне соединения. Не задаётся вместе с `remote_ip_prefix`. При изменении ресурс будет пересоздан.
- `remote_ip_prefix` (String) Диапазон адресов на другой стороне соединения в нотации CIDR. Не задаётся вместе с `remote_group_id`. При изменении ресурс будет пересоздан.

### Read-Only

- `id` (String) Идентификатор правила. Может меняться при синхронизации с платформой, поэтому правило отслеживается по содержимому.
