### Зависимости

#### Log group ID

Можно получить через консоль → раздел **Мониторинг и логи** → **Лог-группы**. В списке лог-групп будет отображаться UUID каждой.

#### Specification ID

Нужное значение для идентификатора спецификации (``specification_id``) можно получить из поля ``specifications.id`` с помощью датасорса ``cloudru_evolution_clickhouse_specification_collection``.
