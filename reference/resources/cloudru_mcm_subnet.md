
# cloudru_mcm_subnet (Resource)

Подсеть внутри сети проекта.

## Example Usage

```terraform
resource "cloudru_mcm_network" "private" {
  name          = "net-private-01"
  platform_name = "ops-01"
  subnet_range  = "10.20.0.0/16"
}

resource "cloudru_mcm_subnet" "app" {
  # Идентификатор сети. Поле неизменяемое: при изменении ресурс будет пересоздан.
  network_id = cloudru_mcm_network.private.id

  # Диапазон адресов подсети в нотации CIDR (IPv4). Поле неизменяемое.
  cidr = "10.20.1.0/24"

  # Название и описание подсети меняются без пересоздания.
  name        = "subnet-app"
  description = "Подсеть приложений"

  # Адрес шлюза. Если не задан, его выбирает платформа.
  gateway_ip = "10.20.1.1"

  # Включение DHCP. Если не задано, остаётся значение платформы.
  enable_dhcp = true

  # Адреса DNS-серверов (IPv4). Если убрать атрибут из конфигурации, список будет очищен.
  dns = ["8.8.8.8", "1.1.1.1"]

  # Статические маршруты. Если убрать атрибут из конфигурации, маршруты будут удалены.
  host_routes = [
    { destination = "10.30.0.0/16", nexthop = "10.20.1.254" },
  ]

  # Пулы адресов для назначения. Если не заданы, их определяет платформа.
  allocation_pools = [
    { start = "10.20.1.10", end = "10.20.1.200" },
  ]
}
```

## Schema

### Required

- `cidr` (String) Диапазон адресов подсети в нотации CIDR, например `10.20.1.0/24`. При изменении ресурс будет пересоздан.
- `name` (String) Название подсети.
- `network_id` (String) Идентификатор сети, в которой создаётся подсеть. При изменении ресурс будет пересоздан.

### Optional

- `allocation_pools` (Attributes List) Пулы адресов, из которых назначаются IP-адреса. Если не заданы, их определяет платформа. (see [below for nested schema](#nestedatt--allocation_pools))
- `description` (String) Описание подсети.
- `dns` (List of String) Адреса DNS-серверов подсети. Если убрать атрибут из конфигурации, список будет очищен.
- `enable_dhcp` (Boolean) Признак включённого DHCP в подсети. Если не задан, остаётся значение платформы.
- `gateway_ip` (String) Адрес шлюза подсети. Если не задан, его выбирает платформа.
- `host_routes` (Attributes List) Статические маршруты подсети. Если убрать атрибут из конфигурации, маршруты будут удалены. (see [below for nested schema](#nestedatt--host_routes))

### Read-Only

- `created_at` (String) Дата и время создания подсети в формате RFC 3339.
- `id` (String) Идентификатор подсети.
- `updated_at` (String) Дата и время последнего изменения подсети в формате RFC 3339.

### Зависимости

#### Network ID

``network_id`` — атрибут ``id`` ресурса ``cloudru_mcm_network``.

### Ограничения

- ``name``, ``description``, ``gateway_ip``, ``enable_dhcp``, ``dns``, ``host_routes`` и ``allocation_pools`` меняются на месте; удаление ``dns`` или ``host_routes`` из конфигурации очищает список.
- ``allocation_pools`` без значения в конфигурации берутся у платформы; удалить их, убрав атрибут, нельзя — задайте нужные пулы явно.
- Удалить шлюз через Terraform нельзя: если убрать ``gateway_ip`` из конфигурации, остаётся текущее значение.
- Адреса ``cidr``, ``gateway_ip``, ``dns``, ``host_routes`` и ``allocation_pools`` — только IPv4.
- Изменение ``network_id`` или ``cidr`` пересоздаёт подсеть.
