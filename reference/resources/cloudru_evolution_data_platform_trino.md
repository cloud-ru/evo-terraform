## Зависимости

### Project ID

Нужное значение для идентификатора проекта (``project_id``) можно получить из поля ``projects.id`` с помощью датасорса ``cloudru_evolution_organization_project_collection``.

### Cluster ID

Нужное значение для идентификатора кластера (``cluster_id``) можно получить из поля ``clusters.id`` с помощью датасорса ``cloudru_evolution_data_platform_cluster_collection``. Если нужного кластера не существует, его можно создать с помощью ресурса ``cloudru_evolution_data_platform_cluster``.

### Network configuration

- Нужное значение для подсети (``network_configuration.subnet_id``) можно получить из поля ``subnets.id`` с помощью датасорса ``cloudru_evolution_compute_subnet_collection``.
- Идентификатор зоны доступности (``network_configuration.zone_id``) находится в поле ``subnets.zone.id`` выбранной подсети. Список зон также можно получить из поля ``zones.id`` датасорса ``cloudru_evolution_compute_zone_collection``.

### Node configuration

- Нужное значение для флейвора (``node_configuration.flavor_id``) можно получить из поля ``flavors.id`` с помощью датасорса ``cloudru_evolution_data_platform_trino_flavor_collection``.
- Значения ``min_count`` и ``max_count`` должны находиться в диапазоне ``flavors.min_node_count``–``flavors.max_node_count`` выбранного флейвора.

Подсеть, зона доступности и флейвор должны быть доступны в проекте, в котором создается Trino.

### Basic auth

В ``basic_auth.users.password_secret_id`` указывается идентификатор секрета из Secret Manager, содержащего пароль пользователя. Идентификатор секрета можно получить в консоли в разделе **Secret Manager**.

### Log group ID

Можно получить через консоль → раздел **Мониторинг и логи** → **Лог-группы**. В списке лог-групп будет отображаться UUID каждой.

### Catalog IDs

Нужные значения для каталогов (``catalog_ids``) можно получить из поля ``catalogs.id`` с помощью датасорса ``cloudru_evolution_data_platform_trino_catalog_collection``. Если нужного каталога не существует, его можно создать с помощью ресурса ``cloudru_evolution_data_platform_trino_catalog``.

### Version ID

Нужное значение для версии (``version_id``) можно получить из поля ``trino_versions.id`` с помощью датасорса ``cloudru_evolution_data_platform_trino_version_collection``.
