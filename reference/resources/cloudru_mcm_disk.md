
# cloudru_mcm_disk (Resource)

Отдельный диск, который можно подключить к виртуальной машине через `cloudru_mcm_disk_attachment`.

## Example Usage

```terraform
resource "cloudru_mcm_disk" "data" {
  # Название диска. Поле неизменяемое: при изменении ресурс будет пересоздан.
  name = "disk-data-01"

  # Название платформы виртуализации и хранилища на ней. Поля неизменяемые.
  platform_name = "vcenter-01"
  datastore     = "datastore-01"

  # Режим работы диска: persistent (по умолчанию), independent_persistent или independent_nonpersistent.
  # Поле неизменяемое.
  mode = "persistent"

  # Размер в МиБ. Размер можно только увеличить.
  size_mb = 102400
}
```

## Schema

### Required

- `datastore` (String) Название хранилища, в котором размещается диск. При изменении ресурс будет пересоздан.
- `name` (String) Название диска. При изменении ресурс будет пересоздан.
- `platform_name` (String) Название платформы виртуализации, на которой создаётся диск. При изменении ресурс будет пересоздан.
- `size_mb` (Number) Размер диска в МиБ, кратный 1024 (шаг 1 ГиБ). Размер можно только увеличить.

### Optional

- `mode` (String) Режим работы диска: `persistent` — изменения сохраняются после выключения машины, `independent_persistent` — изменения записываются немедленно и не участвуют в снимках состояния, `independent_nonpersistent` — изменения теряются при выключении машины. По умолчанию `persistent`. При изменении ресурс будет пересоздан.

### Read-Only

- `datastore_path` (String) Путь к файлу диска в хранилище.
- `id` (String) Идентификатор диска.

### Зависимости

#### Platform, Datastore

``platform_name`` — название платформы виртуализации проекта, ``datastore`` — название хранилища на этой платформе. Их можно посмотреть в консоли MCM.

### Ограничения

- Размер диска можно только увеличить, с шагом 1 ГиБ (``size_mb`` кратен 1024).
- Импорт не поддерживается: сервис не хранит название и режим, с которыми создан диск.
