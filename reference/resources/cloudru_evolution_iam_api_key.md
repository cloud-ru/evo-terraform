## Зависимости

### Service account ID

Нужное значение для идентификатора сервисного аккаунта (``service_account_id``) можно получить из ``service_accounts.id`` датасорса ``cloudru_evolution_iam_service_account_collection``. В ``target`` датасорса укажите ``customer_id`` или ``project_id``, в области которого создан сервисный аккаунт.

### Product codes

Коды продуктов для поля ``product_codes`` можно получить из поля ``products.code`` датасорса ``cloudru_evolution_iam_api_key_product_collection``.
