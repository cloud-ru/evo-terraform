## Зависимости

### Project ID

Нужное значение для идентификатора проекта (``project_id``) можно получить из поля ``projects.id`` с помощью датасорса ``cloudru_evolution_organization_project_collection``.

### Connector configuration

Укажите только один блок конфигурации коннектора: ``postgresql``, ``mysql``, ``oracle``, ``mariadb``, ``mssql``, ``clickhouse``, ``mongodb``, ``metastore``, ``iceberg``, ``connection_hub`` или ``kafka``.

В блоке ``iceberg`` укажите только один тип каталога: ``hive_metastore``, ``rest``, ``jdbc`` или ``nessie``. В ``kafka.table_description_supplier`` укажите только один источник описаний таблиц: ``manual`` или ``confluent``.

### Secret IDs

Во всех продуктах, где требуется ``password_secret_id``, должен указываться идентификатор секрета из Secret Manager, содержащего пароль пользователя соответствующей системы.

В продуктах (``metastore`` и ``iceberg``), где требуются ``access_key_secret_id`` и ``secret_key_secret_id``, должны указываться идентификаторы секретов из Secret Manager, содержащих соответственно ключ доступа и секретный ключ S3. Идентификаторы секретов можно получить в консоли в разделе **Secret Manager**.

### Thrift URI

Для ``metastore.thrift_uri`` и ``iceberg.hive_metastore.thrift_uri`` можно использовать атрибут ``thrift_url`` ресурса ``cloudru_evolution_data_platform_metastore`` или поле ``metastores.thrift_url`` датасорса ``cloudru_evolution_data_platform_metastore_collection`` соответственно.

### Connection Hub

Значение для ``connection_hub.connection_id`` можно получить через консоль → **Data Platform** → **Connection Hub**. В списке подключений будет отображаться UUID каждого. В ``connection_hub.target_connector`` укажите название коннектора, настроенного для выбранного подключения.
