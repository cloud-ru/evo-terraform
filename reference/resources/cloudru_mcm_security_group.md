
# cloudru_mcm_security_group (Resource)

Группа безопасности с набором правил. Отдельные правила можно также описывать ресурсом `cloudru_mcm_security_group_rule`.

## Example Usage

```terraform
resource "cloudru_mcm_security_group" "web" {
  # Название группы. По нему группа указывается в network_interfaces.security_groups машины.
  name = "sg-web"

  # Описание группы (необязательно).
  description = "Доступ к веб-серверам"

  # Название платформы виртуализации. Поле неизменяемое: при изменении ресурс будет пересоздан.
  platform_name = "openstack-01"

  # Правила сопоставляются по содержимому, а не по позиции. Дубли правил недопустимы.
  rules = [
    {
      # Направление: ingress — входящий, egress — исходящий.
      direction = "ingress"
      # Протокол: tcp, udp, icmp или any.
      protocol = "tcp"
      # Диапазон портов; для одного порта значения совпадают.
      port_range_min = "22"
      port_range_max = "22"
      # Источник трафика: remote_ip_prefix или remote_group_id (не вместе).
      remote_ip_prefix = "10.0.0.0/8"
      description      = "ssh"
    },
    {
      direction        = "ingress"
      protocol         = "tcp"
      port_range_min   = "443"
      port_range_max   = "443"
      remote_ip_prefix = "0.0.0.0/0"
      description      = "https"
    },
  ]
}
```

## Schema

### Required

- `name` (String) Название группы безопасности. По нему группа указывается в `network_interfaces.security_groups` виртуальной машины.
- `platform_name` (String) Название платформы виртуализации, на которой создаётся группа. При изменении ресурс будет пересоздан.

- `description` (String) Описание группы безопасности.

- `id` (String) Идентификатор группы безопасности.
- `platform_ref` (String) Идентификатор группы на платформе виртуализации.

### Nested Schema for `rules`

Required:

- `direction` (String) Направление трафика: `ingress` — входящий, `egress` — исходящий.
- `protocol` (String) Протокол: `tcp`, `udp`, `icmp` или `any`.

Optional:

- `description` (String) Описание правила.
- `port_range_max` (String) Конец диапазона портов. Для одного порта совпадает с `port_range_min`.
- `port_range_min` (String) Начало диапазона портов. Не задаётся, если правило действует на все порты.
- `remote_group_id` (String) Идентификатор группы безопасности на другой стороне соединения. Не задаётся вместе с `remote_ip_prefix`.
- `remote_ip_prefix` (String) Диапазон адресов на другой стороне соединения в нотации CIDR. Не задаётся вместе с `remote_group_id`.

Read-Only:

- `id` (String) Идентификатор правила.

### Зависимости

#### Platform

``platform_name`` — название платформы виртуализации проекта. Его можно посмотреть в консоли MCM.

### Правила

Правила внутри ``rules`` сопоставляются по содержимому, а не по позиции: перестановка строк не меняет группу. Два правила с одинаковыми параметрами недопустимы — платформа отклоняет дубли.

Не описывайте одно и то же правило одновременно в ``rules`` и отдельным ресурсом ``cloudru_mcm_security_group_rule``.
