## Зависимости

### Project ID

Нужное значение для идентификатора проекта (``project_id``) можно получить из поля ``projects.id`` с помощью датасорса ``cloudru_evolution_organization_project_collection``.

### Network configuration

- Нужные значения для зон доступности (``network_configuration.zone_ids``) можно получить из поля ``zones.id`` с помощью датасорса ``cloudru_evolution_compute_zone_collection``.
- Нужное значение для VPC (``network_configuration.vpc_id``) можно получить из поля ``vpcs.id`` с помощью датасорса ``cloudru_evolution_vpc_vpc_collection``. Если нужной VPC не существует, ее можно создать с помощью ресурса ``cloudru_evolution_vpc_vpc``.
- Нужное значение для подсети (``network_configuration.subnet_id``) можно получить из поля ``subnets.id`` с помощью датасорса ``cloudru_evolution_compute_subnet_collection``. Если нужной подсети не существует, ее можно создать с помощью ресурса ``cloudru_evolution_compute_subnet``.

Подсеть должна находиться в указанной VPC и одной из выбранных зон доступности. Для всех датасорсов укажите тот же ``project_id``, в котором создается кластер.

### Service account ID

Нужное значение для идентификатора сервисного аккаунта (``service_account_id``) можно получить из поля ``service_accounts.id`` с помощью датасорса ``cloudru_evolution_iam_service_account_collection``. В ``target.project_id`` датасорса укажите проект, в котором создается кластер. Если нужного сервисного аккаунта не существует, его можно создать с помощью ресурса ``cloudru_evolution_iam_service_account``.
