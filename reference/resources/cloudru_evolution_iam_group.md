
# cloudru_evolution_iam_group (Resource)



## Example Usage

```terraform
resource "cloudru_evolution_iam_group" "resource_group" {
  name        = "8cf2b4d1-b26a-4355-b0da-3055a2ec449c"
  description = "35812aa4-fa8b-4c7e-8095-683810c71c5e"
  target = {
    # Нужно заполнить одно из значений - customer_id, project_id.
    customer_id = "e9bdd7e5-103e-4f4b-ab71-5a03d9741f19"
    project_id  = "aa84b020-d4cc-4812-ad80-ac2fb7e18f96"
  }
  ldap_attributes = {
    distinguished_name = "13e88956-f941-4cfe-ab16-4b007dcfc0e5"
    provider_id        = "5a9bb96a-931f-4a0e-98bb-6b480c3bc8d8"
  }
  # Позволяет переопределить дефолтный таймаут провайдера для определенного метода. Если нужно указать бесконечный таймаут, то нужно указать например 0s, тогда таймаута не будет.
  timeouts {
    create = "60m"
    update = "30m"
    delete = "20m"
  }
  # Игнорировать изменения таймаутов: это предотвращает  лишние обновления ресурса при смене значений таймаутов в конфигурации
  # Но следует учитывать, что метод delete в ресурсе читает значение таймаута из стейта и, если его нужно изменить, то этот блок стоит закомментировать
  lifecycle {
    ignore_changes = [timeouts]
  }
}
```

## Зависимости

### Name

Существуют некоторые ограничения для имени группы. Можно использовать:
- Unicode-буквы в любом регистре, включая латиницу и кириллицу.
- Цифры (`0-9`).
- Пробелы.

Длина - от 2 до 255 символов.

Пример:
```
Команда разработки 01
```

### Target

Нужное значение для ``target.customer_id`` можно получить из поля ``customers.id`` с помощью датасорса ``cloudru_evolution_organization_customer_collection``.

Для поля ``target.project_id`` идентификатор проекта можно получить из поля ``projects.id`` с помощью датасорса ``cloudru_evolution_organization_project_collection``.

Укажите только тот идентификатор, на уровне которого должна быть создана группа.
